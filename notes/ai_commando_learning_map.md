## Learning rule

For each important concept:

1. Explain it in plain English.
2. Connect it to a familiar data-engineering mental model.
3. Work through the math with a tiny dataset.
4. Implement the logic from scratch in Python.
5. Visualize it.
6. Reimplement it with a standard library such as scikit-learn.
7. Apply it to a public/synthetic domain example.
8. Ask where it fits in pharma.
9. Ask where it fits in PlantMind.
10. Break something deliberately and explain why it failed.

## Dual-domain application lens

### Pharma AI
Use public or synthetic data only. Example learning problems:
- product/territory performance prediction
- demand forecasting
- account segmentation
- document RAG
- evidence-grounded copilots
- evaluation and governance

### PlantMind 2.0
Use personally owned/public/synthetic assets. Example learning problems:
- sensor feature engineering
- degradation modelling
- anomaly prediction
- physics + ML hybrid reasoning
- maintenance RAG
- diagnostic agents
